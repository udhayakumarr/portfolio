# Udhaya Kumar | Senior Software Engineer Portfolio
A developer portfolio website built with Next.js, TypeScript, and Tailwind CSS.
- **Run Locally**: Use `npm run dev` to start the development server at http://localhost:3000.
- **Build**: Use `npm run build` to generate the production-ready optimized build.
- **Deploy**: Ready to be deployed seamlessly on Vercel or any static hosting provider.
